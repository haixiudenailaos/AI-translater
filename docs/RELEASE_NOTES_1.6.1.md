# LightNovelTranslator 1.6.1

本版本在 V1.6 的基础上集中提升了长任务稳定性、缓存复用、EPUB 处理性能和数据目录可控性。

## 主要更新

- 新增可自定义数据根目录，统一管理缓存、翻译中间记录和译文备份。
- 支持数据目录迁移、冲突检测、中断恢复和项目备份，切换目录时提供安全校验。
- 翻译缓存支持跨启动持久化，并按服务商与模型隔离，减少重复请求。
- 优化队列并发、取消和重试状态管理，完善任务摘要与安全重译操作。
- EPUB 导入复用 item 索引并增加轻量缓存清单，降低大型 EPUB 重复扫描和缓存命中的读取成本。
- 优化图片资产存储、导出和原子文件写入，增强异常恢复及资源边界校验。
- 图片下载统一使用 `httpx` 流式传输，保留 HTTPS、可信域名、重定向、大小、MIME 和图像解码校验。
- 改善自动保存、编码检测和大文件处理路径，减少主线程阻塞和不必要的磁盘写入。
- 删除未使用的 `requests`、`aiohttp`、`openai`、`pydantic` 运行依赖，缩小安装和构建体积。
- 全仓库 Pyright 类型检查升级为阻断式 CI 门禁，并补充缓存、EPUB、并发、编码与存储测试。

## 发布产物

- Windows：`LightNovelTranslator-1.6.1-Windows-x64.exe`
- macOS：`LightNovelTranslator-1.6.1-macOS.app.zip`

## 升级说明

- 原有配置会继续兼容；首次启动时仍使用当前平台默认数据目录。
- 如需调整数据位置，请在设置中选择新的数据根目录，并按提示决定是否迁移旧数据。
- API Key 继续存储在系统密钥环中，不会写入仓库配置文件或发布产物。
