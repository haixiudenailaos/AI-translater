# requirements-image-manga.txt
# ============================================================================
# 漫画翻译模块 (manga-image-translator) 依赖锁定
#
# 用途：为图片翻译默认 Manga Provider 提供深度学习依赖。
# 本文件与 requirements.txt 互补，仅在需要启用图片翻译功能时安装：
#   python -m pip install -r requirements-image-manga.txt
#
# 应用支持 Python 3.10 及以上。部分本地漫画翻译依赖可能有自己的 Python
# 版本或 wheel 限制；这只影响对应的可选 Provider，不影响文本翻译功能启动。
#
# 设计原则：
# - 所有版本经过验证，确保 CPU/GPU 均可运行（默认 device=auto）。
# - 不污染主 requirements.txt，未启用图片翻译的项目无需安装。
# - 与 src/infrastructure/image_translation/manga_provider.py 的惰性导入对齐：
#   若本文件未安装，Manga Provider.validate() 会返回明确错误而不是崩溃。
#
# P1-12：本清单是 Full Edition 的输入约束；发布构建使用平台对应的
# `requirements-full-*.lock.txt`，并通过 `--require-hashes` 安装。
# 生成命令见 tools/generate_dependency_locks.py。额外索引的 Rust wheel 已
# 固定版本，hash 由平台 lock 文件记录，避免供应链解析漂移。
# - PyInstaller 在 CI 中固定（见 .github/workflows/build.yml 的
#   PYINSTALLER_VERSION），不在此文件声明，避免与打包工具链耦合。
# ============================================================================
